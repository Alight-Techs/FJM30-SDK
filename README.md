# FJM30 SDK

Software Development Kit for the FJM30 SDR SoC platform.

## Overview

The FJM30 SDK provides development resources for the FJM30 SDR SoC.

### Supported Environment

- Vivado 2018.3
- Embedded Linux
- PetaLinux
- JTAG Programming
- Flash Programming

## Repository Structure

### FPGA

Reference FPGA projects and design files.

### Linux

Linux BSP and operating system resources.

### Drivers

Device drivers and low-level support.

### Examples

Reference applications and demonstration projects.
